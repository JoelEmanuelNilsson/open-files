The bar never fills. Bin it, or give it a job?

Twelve cells sit at the end of your prompt box, warning that compaction is coming. Compaction is switched off. This page is one decision: what goes in those twelve cells.

Not proved yet

Anthropic's utilization header reads 0.67. Two probes two minutes apart moved it by 0.01 under ordinary work, which only makes sense as a fraction of one — but no document says so. One check against Claude Code's own /usage settles it.

Nothing in the harness reads these headers today. absent rg -n "ratelimit" pi/kit returns nothing.

Background agents report start and settle, nothing in between. There is no progress to draw. absent

Here is the rule, at the fullest it ever gets

Those eighteen columns are the most protected thing in the frame. As the terminal narrows the rule gives up the timer, then the task count, then it squeezes the branch — and the gauge is the last label standing derived. Whatever lives there is, by construction, the frame's most important fact.

It is an alarm for a fire that cannot start

And the event it warns about is off: compaction is disabled in settings, replaced by handoff, where the model writes its own summary when you ask derived.

$ jq -c '.compaction' ~/.pi/agent/settings.json {"enabled":false}

The code says so itself, in its own doc comment: "it is the only thing on screen that says compaction is coming." That sentence was true once. It is the reason the gauge outranks everything else in the rule, and it is now false.

Meanwhile, the limit that does stop you is invisible

Every Claude response carries your usage back in its headers, free, on a hook this harness already listens to after_provider_response. Nothing reads them. Here are both numbers as they stood at 22:35 tonight, drawn on the same twelve cells.

Same twelve cells. One is a fuel gauge on a parked car. The other is the tank you are driving on, and you have never seen it.

DICTIONARY

the frame

gauge
The twelve cells and their percentage, at the right end of the bottom rule.
the drop order
What the rule gives up as the pane narrows. The gauge goes last.
compaction
Throwing the conversation away for a summary. Switched off here.
context window
Tokens one request can hold. One million.

the budget

the 5-hour window
Anthropic's short usage claim. Refills on a fixed boundary.
the 7-day window
The weekly claim. Carries the Opus cutoff at half.
utilization
Fraction of a window already spent. 0.67.
elapsed
How far through the five hours the clock is. Derived from the reset header.
pace
Spend divided by elapsed. Above one, you run out early.
representative-claim
A header naming which window is currently binding.

the options

the pace bar
Spend as fill, the clock as a tick, the gap coloured by which is ahead.
the swarm strip
One glyph per background agent, lit while it runs.
delete it
Drop the cells, keep the number as text. The baseline.

the plumbing

after_provider_response
The pi hook carrying response status and headers. Already used here.
