# Help

## Find a file

- **Sidebar**: show or hide the file list. Click a folder to open it, or a file to read it.
- **Search**: type to find a file. Choose **File names** or **File contents**, then click a result.
- Open files stay as tabs at the top. Click a tab to go back to it.
- **Formatted / Source**: click to change the Markdown view. It remembers your choice and does not change the file. Writing shows source.

## Branches

- **Branches**: pick a branch to read its saved files. Click **Branches** again to dismiss the list.
- The top line shows **Reading branch** while you do this. Your own files do not change.
- **Back**: return to your files.
- **Switch project**: change your project to the branch you are reading. It asks first.
- **Push**: send your saved commits to the remote. It asks first.

## Change a file

- **Edit** is only for `.md` and `.txt` files. Click it to write; click again to stop editing.
- **Save**: save your writing and go back to reading. The file stays open.
- **Close** while editing: stop editing, not close the file. Unsaved writing offers **Save changes**, **Discard changes**, or **Cancel**.
- **File actions**: new file, new folder, rename, move, delete.
- Edit and File actions are off while reading a branch.

## Close

- **Close**: dismiss a menu or stop editing. It never closes your document. Use a tab’s **×** to close that file.
- **Quit**: leave Neovim. It asks about unsaved changes.
- **Search**, **Branches**, **File actions**, and **More** dismiss their menu when clicked again.
- **More** holds extra actions and Help on narrow screens.

## Shortcuts

| Keys | Action |
|---|---|
| `Space e` | Sidebar |
| `Ctrl-P` | Search file names |
| `Space s` | Search file contents |
| `Ctrl-F` | Search this file |
| `Ctrl-S` | Save |
| `F1` | This help |
